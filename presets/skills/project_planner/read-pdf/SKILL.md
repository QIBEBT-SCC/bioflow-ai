# PDF 附件读取指南

## 附件识别

- 对话中的 `<PDF id="..." .../>` 只是附件占位标识，并不包含正文内容。在调用 `view_pdf` 读取之前，不得声称已了解其中的任何内容。
- 调用 `view_pdf` 时，传入标签中的确切 `file_id`。

## 读取策略

1. **长文档先做段落级过滤**：对于论文或较长的补充材料，优先传入具体的 `query` 进行段落级语义筛选（例如先检索 `Methods / Bioinformatics / Pipeline` 或 `Data availability / Samples / Sequencing` 相关段落），避免一次性把整篇无关正文灌入上下文。
2. **识别省略与按需补查**：
   - 筛选结果会按原文顺序返回命中段落及其上级标题，并用 `…（已省略 N 段）` 标出跳过的部分。
   - 如果发现关键工具名、流程衔接、输入数据特征或样本分组被省略，或者工具返回没有超过相似度阈值的段落，应换用更具体或不同角度的 `query` 补充检索。
   - 若多轮检索仍缺少上下文全貌，或文档本身较短，再省略 `query` 读取全文。
3. **图表信息限制**：PDF 解析仅保留图片图注等文本信息，不包含图片本体，切勿臆测图表中未在文字里出现的细节。

## 信息提取与查证

- **数据整理阶段**：重点提取样本来源、实验设计、测序平台与双/单端布局、配对/分组关系及需要提取的元数据线索。
- **分析规划阶段**：重点提取方法学路线、工具选择与科学约束。
- 仅当文档提到你不熟悉的冷门工具、且不查清就无法合理规划时，才使用 `web_run` 检索补充。
