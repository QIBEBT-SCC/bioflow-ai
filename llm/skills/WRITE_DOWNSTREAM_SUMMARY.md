# Skill: Write downstream summary

If additional downstream analysis is required after the current workflow is completed, you need to use the `downstream_summary` node, connect the result files used for downstream analysis to it, and
fill in the node's `prompt` field.

## Node Input Handles

The `downstream_summary` node has only one input handle, `input_files`. You need to connect **all** result files generated by the current workflow that may be used for downstream analysis to this
handle.

## How To Write Prompt

What you need to write is a clear instruction, not vague advice. This includes:

- Which language to use for downstream analysis (Python or R)
- Which analysis tasks to perform (e.g., standard clustering, task-specific visualizations, etc.)
- Which upstream result files generated by the workflow are required for the analysis (this should correspond to the files you connected to `input_files`)
