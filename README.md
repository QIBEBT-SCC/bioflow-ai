# BioFlow AI

BioFlow AI is a graph-driven intelligent bioinformatics analysis platform. It organizes analysis tools, data, and compute tasks into visual node-based workflows, while AI agents help manage samples, build workflows, diagnose execution problems, and repair analysis pipelines.

## System Requirements

- Linux (recommended)
- Python 3.13+
- [uv](https://docs.astral.sh/uv/)
- One of the following container runtimes:
  - Docker with the Docker Compose plugin
  - Podman with Podman Compose

A rootless container runtime is recommended to prevent files generated by analysis tasks from being owned by the host's root user.

## Installation and Initialization

In an empty deployment directory, install `bioflow-ai` from PyPI:

```bash
uv init --bare --python 3.13
uv add bioflow-ai
uv run bioflow-ai auto-init
```

To install a specific pre-release version, pin it explicitly (for example, `uv add 'bioflow-ai==1.0.0b1'`), or download the `.whl` from [GitHub Releases](https://github.com/QIBEBT-SCC/bioflow-ai/releases) for offline deployment and pass its path to `uv add` instead. Add `--extra podman` to the install command when using Podman. Run the initializer and backend processes from the same deployment directory. The initializer puts editable Skills in `presets/skills/` and prepares the database initialization files in `presets/sql/`. Re-running it fills in missing files and preserves existing copies.

### From a source checkout

```bash
git clone https://github.com/QIBEBT-SCC/bioflow-ai.git
cd bioflow-ai
```

With Docker:

```bash
uv sync
uv run bioflow-ai auto-init
```

With Podman:

```bash
uv sync --extra podman
uv run bioflow-ai auto-init
```

### Start the backend

The initializer prepares the services and database tables, then configures the embedding model and chat models together. The final stage creates the administrator account, imports system presets, builds the vector indexes, and offers the optional test dataset. See the [Automatic Initialization guide](https://bioflow-ai-doc.vercel.app/docs/configuration/initialization).

After initialization, start the API (which also hosts the workflow dispatcher), the shared execution worker, and the agent worker in separate terminals:

```bash
uv run bioflow-ai api
uv run bioflow-ai execution-worker --concurrency 4
uv run bioflow-ai agent-worker
```

Open `http://localhost:3000` in your browser. If a default port is already in use, the initializer selects an available port and displays it in the terminal.
